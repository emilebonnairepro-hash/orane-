# Politiques de la boutique ORANE (brouillons à valider)

Ces textes vont dans Shopify : **Paramètres → Politiques**. Les liens du pied de page du site
(`/policies/shipping-policy`, `/policies/refund-policy`, `/policies/terms-of-service`) affichent une page introuvable
tant qu'ils ne sont pas publiés.

Tout ce qui est entre `[crochets]` est à compléter avec les informations de ta société.
Les textes suivent le Code de la consommation français (droit de rétractation de 14 jours, garanties légales)
mais ne remplacent pas la relecture d'un juriste.

| Fichier | Politique Shopify | URL sur le site |
|---|---|---|
| `livraison.html` | Politique d'expédition | /policies/shipping-policy |
| `retours.html` | Politique de remboursement | /policies/refund-policy |
| `cgv.html` | Conditions d'utilisation | /policies/terms-of-service |
| `coordonnees.html` | Coordonnées (mentions légales) | /policies/contact-information |
